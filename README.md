# kaemmung

A Claude Code skill: systematic grooming of an overgrown work
carrier (backlog, queue, ledger segment). Diagnoses WHY the carrier
grows before pruning — blocked exit, capture-dominance, grade
inflation, unresolved boundaries — because each disease has its own
cure and a generic tidy-up regrows. Closes with an accounting
reconciliation, never a feeling of tidiness.

Sibling of [begehung](https://github.com/Gunther-Schulz/begehung)
(begehung walks the system for defects; kaemmung walks the carriers
for overgrowth).

Install as a Claude Code plugin from this repo's `plugin/`
directory. Design record: `PLAN.md`; incident provenance:
`dev-notes/OBSERVATIONS.md`.
