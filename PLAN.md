# Kämmung — the plan (persisted 2026-08-11)

Naming lineage: the office's established term for the pass (the
2026-07-17 backlog-kaemmer dispatch named it) — a deliberate
DEVIATION from skill-craft's canonical-term rule, surfaced rather
than silent: the industry-canonical term is "backlog grooming", but
its priors are scrum refinement ceremonies (estimation,
prioritization, splitting) — the wrong behavior for this skill,
whose distinctive content is diagnose-then-cure with an accounting
close. A term recruiting wrong priors is worse than one recruiting
none. Cold-probe both candidates before first release past trial
(BACKLOG).

Consumer of this file: the sessions that trial and extend the
skill. Every design decision from the founding discussion is here;
the conversation is not the carrier.

## Mission and lineage

A thin, top-tier-first CARRIER-maintenance skill: diagnose why a
work carrier (backlog, queue, ledger segment) grows without end,
apply the cure matching the disease, close with a reconciliation.
Sibling of begehung (begehung walks the SYSTEM for defects;
kaemmung walks the CARRIERS for overgrowth); built skill-first,
probe-then-certify, exactly as statiker and begehung were.

## The founding evidence (three incidents, all 2026-08-11 or prior)

1. **claude-code-cache-fix BACKLOG.md**: 38 → 14,396 lines in 13
   days, monotone over every sampled commit, one retirement pass
   ever; rebuilt 2026-08-11 with the three-grade declaration
   (READY = derived capped head, RECORD, PARKED), a mechanical
   booking bar (`tools/backlog-lint.mjs --ready-bar`), and a
   `## Done` closure home. Diseases: capture-dominance + grade
   inflation + unresolved boundaries (63 of 100 READY entries named
   no file; an opus session repeatedly failed to batch them, a
   census-join over resolved boundaries succeeded).
2. **pbs-office FEATURE-BACKLOG.md**: 578 → 2,769 lines since its
   own combing pass of 2026-07-17; ~98 closure markers against ~47
   live entries in the live sections; the file outgrew the 2,500
   ledger lines its header names as its reason to exist. Disease:
   blocked exit — the carrier's own care rule ("never delete
   silently") was lived as strike-and-keep, forbidding the exit.
3. **The trigger that never fired**: the operator corpus carried
   the retirement tripwire as prose; both carriers crossed it
   unnoticed until an operator asked. Cure landed as mechanism, not
   more prose: session-scan.py `retirement_pressure` (cache-fix
   incident) and `exit_pressure` (pbs-office incident), each
   red-proven on its motivating case.

## Evaluation (built before the procedure text was finalized)

### Tier 1 — triggering query set

Should trigger: "unser backlog nimmt kein ende, was tun?" ·
"räum das FEATURE-BACKLOG auf — cull/merge/batch?" · "kämmung von
pbs-office" · "the session banner says exit pass owed — what now?"
· "zu viele READY-einträge, niemand glaubt der liste mehr" ·
"this ledger file has grown huge, can we shrink it?"

Should NOT trigger: "book this finding in the backlog" (carrier's
own rules) · "mach ein robustheits-review von pbs-office"
(begehung) · "diagnose this bug" (diagnosing-bugs) · "simplify
this module" (code cleanup) · "review this PR" (review).

Competitors for the router set: begehung, statiker,
diagnosing-bugs, simplify, review, skill-craft.

### Tier 2 — behaviour-delta signature (un-fakeable artifacts)

1. Measurement table BEFORE any edit (lines, markers, ratio,
   grade counts — commands shown).
2. Named disease class per cure applied (no generic tidy).
3. Reconciliation that adds up: before = moved + kept + dropped
   (+ named gaps), per section.
4. Negative grep with the pattern shown live on a known positive.
5. No tidy-claim — re-measured numbers + booked pass date instead.

Control expectation (from begehung's three-arm result): a
corpus-loaded control will produce honest partial conduct; the
skill-exclusive part is expected to be the diagnosis taxonomy and
the accounting close. Measure with the same three-arm design
(with / without / one-sentence ablation).

## Boundaries

- The skill diagnoses and prescribes; the pass itself defaults to
  a dispatch under the operator's dispatch discipline.
- Carrier-design rules (grades, exits, thirds) belong to the
  operator corpus (accretion module); the skill cites, never
  restates — its content is the diagnosis-to-cure mapping and the
  closing discipline.
